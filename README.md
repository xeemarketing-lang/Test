# FMCG Advanced Analytics Dashboard

This dashboard is an advanced FMCG business intelligence template for field force and distributor operations.

## Advanced analytics modules included

1. **Field Force Management**
   - Beat plan adherence
   - Outlet coverage %
   - Call compliance
   - Productive calls %
   - Daily route tracking
2. **Booker Performance**
   - TGT vs ACH
   - Strike rate analysis
   - SKU productivity
   - Average bill value
   - Conversion rate
3. **Brand Performance**
   - Brand-wise TGT vs ACH
   - Market share by category
   - Contribution margin
   - Growth trajectory
4. **Customer Analytics**
   - Churn prediction indicator
   - Retention rate
   - Customer lifetime value
   - Acquisition cost
   - NPS score
5. **SKU Analytics**
   - SKU per bill
   - Basket analysis indicator
   - SKU profitability
   - Fast/slow moving SKU mix
   - Cannibalization effect
6. **Trade Marketing**
   - Promotion ROI
   - Scheme effectiveness
   - Trade spend analysis
   - Display compliance
7. **Supply Chain Deep Dive**
   - Distributor inventory days
   - Primary vs secondary sales ratio
   - Stock-out analysis
   - Perfect order %

## Run locally

Use the preview-compatible server:

```bash
python3 server.py
```

Then open: `http://localhost:8000`

(If needed: `python3 -m http.server 8000`)

## Note

Current values are sample/mock data for demonstration. Replace with your DMS/SFA/ERP pipelines for production use.
